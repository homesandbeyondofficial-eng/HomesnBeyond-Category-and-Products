# Homes N Beyond Category and Product SEO/AEO Drafts

This repository is used to prepare SEO/AEO content for manual review before anything is published to Shopify.

## Workflow
- Draft category and product content in Markdown.
- Keep all product claims tied to verified product specifications.
- Preserve existing product names, URLs, dimensions, materials, construction and care details unless a correction is explicitly verified.
- Do not publish content directly to Shopify from this repository.
- Reviewers manually approve and publish content.
